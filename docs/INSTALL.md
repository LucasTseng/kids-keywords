# 打字 · 背默练习 — 跨平台安装部署手册

本手册说明如何在 **Windows**、**macOS**、**Android 平板**、**iPadOS 平板** 上安装与使用「打字 · 背默练习」应用。

---

## 一、各平台方案概览

| 平台 | 方案 | 是否需要网络 | 离线使用 | 安装来源 |
| --- | --- | --- | --- | --- |
| Windows | Electron 桌面应用（安装版 / 便携版） | 首次安装不需要 | ✅ 完全离线 | 本地 EXE 或 GitHub Release |
| macOS | Electron 桌面应用（DMG） | 首次安装不需要 | ✅ 完全离线 | GitHub Actions 构建产物 |
| Android 平板 | PWA（渐进式 Web 应用） | 首次安装需要 | ✅ 安装后离线可用 | 浏览器添加到主屏幕 |
| iPadOS 平板 | PWA（渐进式 Web 应用） | 首次安装需要 | ✅ 安装后离线可用 | Safari 添加到主屏幕 |

> **说明**：移动端（Android / iPadOS）采用 PWA 方案，因为打包原生 App（APK / IPA）需要各自平台的开发者账号与签名流程，而 PWA 可以在浏览器中直接「安装到主屏幕」，获得与原生 App 几乎一致的体验（全屏、离线、独立图标）。

---

## 二、Windows 安装

### 方式一：安装版（推荐）

1. 获取安装包 `打字背默练习-安装包-{版本}-x64.exe`。
2. 双击运行安装程序。
3. 按照向导选择安装目录（可自定义），点击「安装」。
4. 安装完成后，桌面与开始菜单会生成「打字背默练习」快捷方式。
5. 双击快捷方式即可启动。

### 方式二：便携版（免安装）

1. 获取便携版 `打字背默练习-便携版-{版本}-x64.exe`。
2. 将其复制到任意目录（如 U 盘、桌面）。
3. 双击即可直接运行，无需安装。
4. 首次运行可能被 Windows SmartScreen 拦截，点击「更多信息」→「仍要运行」即可。

## 三、macOS 安装

macOS 版本通过 GitHub Actions 在 macOS Runner 上构建，产物为 DMG 镜像。

### 获取 DMG

- 推送 `v*` 标签后，GitHub Actions 会自动构建并把 DMG 附加到对应 Release。
- 也可在 Actions 页面手动触发 `Release Desktop` 工作流，从 Artifacts 下载。

### 安装步骤

1. 下载 `打字背默练习-{版本}.dmg`（含 x64 与 arm64 两种架构，自动适配 Intel / Apple Silicon）。
2. 双击打开 DMG。
3. 将「打字背默练习」图标拖拽到「Applications」文件夹。
4. 打开「启动台」或「应用程序」，找到「打字背默练习」并启动。

### 首次打开提示「无法打开」的处理

macOS 默认会阻止未签名的应用：

1. 右键点击应用图标，选择「打开」。
2. 在弹出的对话框中再次点击「打开」。
3. 之后即可正常启动。

> 如需彻底消除该提示，可在「系统设置 → 隐私与安全性」中允许该应用运行。

## 四、Android 平板安装（PWA）

Android 平板通过浏览器将 PWA「安装到主屏幕」，获得类原生 App 体验。

### 环境要求

- Android 8.0 及以上
- 推荐使用 **Chrome** 或 **Edge** 浏览器（PWA 支持最完整）

### 安装步骤

1. 打开浏览器，访问应用部署后的网址（GitHub Pages 地址或你的自定义域名）。
2. 等待页面完全加载（首次会下载并缓存离线资源）。
3. 点击浏览器右上角菜单（⋮）。
4. 选择「添加到主屏幕」或「安装应用」。
5. 在弹出的对话框中点击「安装」。
6. 安装完成后，桌面会出现「打字 · 背默练习」图标。

### 使用说明

- 点击桌面图标即可全屏启动应用，无浏览器地址栏。
- 首次安装后，即使断网也可正常使用（资源已缓存）。
- 成绩保存在设备本地（IndexedDB），不会上传到服务器。

### 更新方式

- PWA 会在联网时自动检测并静默更新 Service Worker。
- 关闭应用后重新打开即可加载最新版本。

## 五、iPadOS 平板安装（PWA）

iPadOS 通过 Safari 将 PWA 添加到主屏幕。

### 环境要求

- iPadOS 14.0 及以上
- 使用 **Safari** 浏览器（iOS/iPadOS 仅 Safari 支持完整 PWA 能力）

### 安装步骤

1. 打开 Safari，访问应用部署后的网址（GitHub Pages 地址或你的自定义域名）。
2. 等待页面完全加载。
3. 点击 Safari 底部工具栏的「分享」按钮（方框带向上箭头）。
4. 在弹出菜单中选择「添加到主屏幕」。
5. 确认名称（默认为「打字 · 背默练习」），点击右上角「添加」。
6. 返回主屏幕，找到应用图标并点击启动。

### 使用说明

- 点击图标后以独立全屏模式运行，无 Safari 浏览器界面。
- 支持离线使用（首次联网安装后资源已缓存）。
- 成绩保存在设备本地。

### 注意事项

- iOS/iPadOS 的 PWA 存储空间限制为 50MB 左右，本应用资源远小于该限制，可正常离线运行。
- 若需清除数据，可在「设置 → Safari → 高级 → 网站数据」中删除对应站点数据。

## 六、本地开发与自行打包

如需自行构建各平台包，步骤如下：

### 前置条件

- Node.js 20+
- pnpm 9+

```bash
# 安装依赖
pnpm install

# 构建题库与 sql.js 运行时
pnpm build

# 生成应用图标
pnpm icons
```

### Windows 打包

```bash
pnpm app:win
```

产物位于 `release/` 目录：
- `打字背默练习-安装包-{版本}-x64.exe`（NSIS 安装包）
- `打字背默练习-便携版-{版本}-x64.exe`（便携版）

### macOS 打包

> 需要在 macOS 上执行，Windows 环境无法生成 DMG。

```bash
pnpm app:mac
```

产物：`release/打字背默练习-{版本}-{arch}.dmg`

### 通过 GitHub Actions 构建 macOS

在仓库推送 `v*` 标签，GitHub Actions 的 `Release Desktop` 工作流会自动在 macOS Runner 上构建 DMG 并发布到 Release。

### 本地运行 Electron（开发调试）

```bash
pnpm app
```

## 七、常见问题

**Q：PWA 安装后无法离线使用？**
A：确保首次安装时网络畅通，等待页面完全加载后再添加到主屏幕。可在浏览器开发者工具 → Application → Service Workers 中检查缓存状态。

**Q：macOS 提示「应用已损坏」？**
A：这是 macOS Gatekeeper 的安全提示，右键选择「打开」即可，或在「系统设置 → 隐私与安全性」中允许。

**Q：Windows 便携版被杀毒软件拦截？**
A：便携版 EXE 未签名可能被误报，添加信任即可。如需签名，可在 `package.json` 的 build 配置中添加证书信息。

**Q：成绩会同步吗？**
A：当前版本成绩保存在本地设备（IndexedDB），不会跨设备同步。清除浏览器数据或卸载应用会丢失成绩。
