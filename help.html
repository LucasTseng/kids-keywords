⌨️ vkeyboardhand · 帮助

SVG 键盘图 + SVG 手势图 + JavaScript 事件驱动 · 交互式指法教学组件。纯 HTML + JS 实现、零依赖，兼容 Vue / React / Angular 等前端框架

使用说明

  • 打字练习：看英文打英文，下方键盘与手势实时联动，练指法的同时记住拼写。正确字符变绿，输入错误会标红且无法继续，全部打对自动进入下一题。可用两侧按钮或键盘 ← → 切换。
  • 背默练习：只看中文默写英文，下划线数量提示字符总数（含空格与标点）。进入即计时，逐题作答，回车或方向键切换、鼠标点题号跳转；答完点「提交」自动评分并记录成绩。
  • 成绩：提交前输入任意用户名即可，无账号无登录。成绩保存在浏览器本地，可在首页「历史成绩」查看。

键盘实时联动（指法）

直接在键盘上打字即可联动 Shift Alt 等组合键 · 也可用鼠标点击键位演示 · 顶部按钮切换主题
